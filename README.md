ATM Project

A console-based ATM simulation written in C++ using Visual Studio. The user logs in with a 4-digit PIN and can check their balance, deposit money, or withdraw money from a menu.

Features
PIN login with 3 attempts (the account is frozen after 3 wrong tries)
Check account balance
Deposit money and see the updated balance
Withdraw money with an insufficient balance check
Continue or exit prompt after each transaction
Invalid menu option handling
Menu
FOR CHECKING ACCOUNT BALANCE Press=1
FOR DEPOSIT Press=2
FOR WITHDRAW Press=3
FOR EXIT Press=4
Concepts Used
Variables and data types
do-while loops
if / else conditions
switch statement for the menu
Input and output with iostream
Future Improvements
Block negative or zero amounts for deposit and withdrawal
Support multiple accounts
Save balance and transaction history to a file
