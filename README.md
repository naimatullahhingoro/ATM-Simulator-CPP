ATM Project

A simple console-based ATM program written in C++ using Visual Studio.

Features
PIN login with 3 attempts (account is frozen after 3 wrong tries)
Check account balance
Deposit money
Withdraw money, with a check for insufficient balance
Continue or exit prompt after each transaction
Concepts used

Variables, loops (do-while), conditionals (if/else), switch menu, and input/output with iostream.

How to run

Open the .sln file in Visual Studio and press F5.
